# Описание конфликта слияния

## Где возник конфликт:
Конфликт возник в файле `validation.js` при слиянии ветки `feature-add-validation` в `main`.

## Причина конфликта:
В ветке `main` я уже работала с валидацией и добавила проверку в класс Habit.
В ветке `feature-add-validation` была добавлена отдельная функция валидации.
Git не смог автоматически объединить изменения, так как обе ветки изменяли связанные файлы.

## Как был разрешен:
1. Открыла файл `validation.js` в Блокноте
2. Увидела маркеры конфликта: `<<<<<<< HEAD`, `=======`, `>>>>>>> feature-add-validation`
3. Оставила функцию валидации из ветки `feature-add-validation`
4. Удалила служебные маркеры Git
5. Выполнима `git add validation.js`
6. Завершила слияние командой `git commit`
